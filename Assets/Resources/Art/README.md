파일을 넣으면 코드 수정 없이 해당 화면에서 자동 교체된다 (`ArtCatalog`).
없는 파일은 X-Box 플레이스홀더로 계속 표시된다.

## 2026-09-22 시안 자산 수령 이후

디자인 시안 자산은 `Assets/UI Image/`(번호 파일명)에 있고, `ArtCatalog`의 별칭표가 게임 데이터 한글명과 잇는다.
이 폴더(`Resources/Art/<분류>/<한글명>.png`)에 같은 이름의 파일을 넣으면 **시안 자산보다 우선** 적용된다
(개별 교체·검증용). 임시 샘플은 두지 말 것 — 남아 있으면 시안 그림을 가린다.
