## 이 문서를 읽는 법

| 이 문서가 답하는 것 | 이 문서가 답하지 않는 것 |
| 무엇을 만드는가 | 왜 그렇게 정했는가 → 통합인계자료 |
| 어떤 화면에 붙는가 | 화면이 어떻게 생겼는가 → 화면설계서 · 와이어프레임 |
| 무엇을 하지 않는가 | 어떤 수치로 만드는가 → 밸런스 문서(화면설계 완성 후) |

## 3. 공통 입력

## 3-1. 손 커서 + dwell

| 항목 | 값 |
| 표시 | 손 위치에 커서 + 진행이 보이는 게이지 |
| 게임 오브젝트 | 2초 유지 시 선택 |
| UI 버튼 | 3초 유지 시 선택 |
| 요리하기 재료 | 1~2초 (기준안 · 검증 후 조정) |
| 중단 | 손이 벗어나면 게이지 초기화 |

게이지가 보이면 그 자리에 머무르면 된다. 게이지 링이 보이면 머무르고, 보이지 않으면 몸을 움직인다. 수확하기와 장보기는 dwell로 선택하지 않는다.

## 3-2. 안전 영역

| 구분 | 범위 |
| 인터랙션 요소 | x 420 ~ 1500 / y 240 ~ 980 |
| 표시 전용 요소 | 제한 없음 (목표 패널 · 경과 시간 · 진행 레일 · 배경) |

예외 3종 — 영상 건너뛰기(영상 밖 우측 상단) · 장보기 일시정지(상단 좌측) · 장보기 발판·점포(게임 설계상 화면 전폭 사용)

## 3-3. 소리

| 상황 | TTS | 효과음 |
| 튜토리얼 · 영상 · 결과 · 전환 | ○ | ○ |
| 게임플레이 중 | ✕ | ○ |

게임 중에는 효과음 + 시각 애니메이션만 쓴다.

## 4. 사용자 기능

## FN-01 대기 · 사람 감지 (SCR-001)
무인 상태에서 타이틀 표시 · 사용자 입력 없음
카메라가 사람을 감지하면 자동으로 FN-02로 이동
이 화면에는 기록 보기를 두지 않는다 (누가 볼지 정해지지 않음)

## FN-02 자세 보정 안내 (SCR-002)
전신이 화면에 들어오도록 안내
체크 항목을 순서대로 충족시키고, 완료되면 자동으로 FN-03으로 이동

## FN-03 사용자 선택 (SCR-003)

| 항목 | 내용 |
| 표시 | 등록된 사용자 카드 (이름 + 아바타 + 배경색) |
| 아바타 | 8종 — 동물 · 과일 · 자연 계열 |
| 배경색 | 등록 시 랜덤 배정 · 식별 수단이 아닌 장식 |
| 비회원 | 「처음이신가요」로 진입 가능 · 기록 저장 안 함 |


## FN-04 모드 선택 (SCR-004)
스토리 게임 / 개별 게임 2종
비회원은 기록 관련 항목을 표시하지 않는다

## FN-05 콘텐츠 로비 (SCR-005) — 개별 모드 전용
게임 3종 선택 + 내 기록 보기
게임 종료 후 이 화면으로 복귀

## FN-06 튜토리얼 재생 (SCR-007 · 012 · 017)

| 항목 | 내용 |
| 구성 | 짧은 영상 + 단계별 설명 |
| 단계 수 | ① 3단계 / ② 4단계 / ③ 4단계 |
| 연동 | 영상 진행에 맞춰 현재 단계를 강조 |
| 실습 | 없음 — 영상을 본 뒤 바로 플레이 진입 |
| 버튼 (개별) | 나가기 · 다시 보기 · 시작하기 3종 |
| 버튼 (스토리) | 나가기 · 시작하기 2종 |

건너뛰기는 튜토리얼에 두지 않는다. 영상 화면(FN-15)에만 있다.

## FN-07 수확하기 플레이 (SCR-008)

| 항목 | 값 |
| 라운드 | 10라운드 고정 |
| 동작 | 목표 작물 위에 손을 올리고 아래로 당김 |
| 선택지 | R1~3 3개 → R4~7 4개 → R8~10 5개 |
| 선택지 종류 | 목표 작물 / 다른 작물 / 벌레 먹은 작물 |
| 정답 | 바구니에 담김 |
| 오답 | 화면 밖으로 휙 날아감 · 라운드 진행과 기록에 반영 |
| 시간 제한 | 없음 |

기록 항목 — 라운드별 선택 작물 · 정답/다른 선택/벌레 구분 · 반응 시간 · 힌트 발동 · 성공 횟수 · 전체 활동 시간

## FN-08 장보기 플레이 (SCR-013)

| 항목 | 값 |
| 라운드 | 10라운드 고정 |
| 동작 | 빛나는 발판으로 걸어가서 멈춤 → 가운데로 복귀 |
| 발판 | R1~R4 3개 → R5~R10 5개 |
| 점포 | 4개 + 장바구니 · 발판과 세로 1:1 정렬 |
| 목표 수 | 1개 → 2개 → 3개 점증 |
| 목표 발판 | 라운드마다 무작위 (안전 제약 4종 적용) |
| 판정 | 발판 도착 시 구매 · 통과는 판정하지 않음 |
| 재판정 | 구매가 처리된 뒤 그 발판을 벗어나기 전까지 없음 |
| 일시정지 | 상단 좌측 (안전 영역 예외) |

고정 경로표는 폐기되었다. 목표 발판은 매 라운드 무작위로 정한다.
기록 항목 — 재료별 구매 판정(20건) · 구매 점포 위치 · 도착까지 걸린 시간 · 라운드 수행 시간 · 힌트 발동 · 좌우 이동 방향별 횟수 · 제대로 산 재료 수 · 성공 횟수 · 전체 활동 시간

상태 문구 3종 — 좋은 변화 확인(초록) / 비슷한 수준(회색) / 비교 기록 부족(회색) ↑↓ 화살표 대신 「늘었어요 / 빨라졌어요 / 줄었어요 / 비슷한 수준」 문구로 표현한다.

## 변화 판정 규칙
변화량 = 최근 구간 값 − 처음 구간 값|변화량| < 0.5   → 「비슷한 수준」구간 수 < 2      → 「비교 기록 부족」

| 지표 | 값이 커짐 | 값이 작아짐 |
| 정확하게 선택 | 늘었어요 | 줄었어요 |
| 평균 반응 시간 | 느려졌어요 | 빨라졌어요 |
| 다른 선택 · 도움 받은 횟수 | 늘었어요 | 줄었어요 |

비교 대상은 그래프 양 끝의 처음 구간과 최근 구간이다. 중간 구간은 계산에 쓰지 않는다. 주간 · 월간 · 일별을 바꾸면 구간 단위만 달라지고 규칙은 같다. 자세한 내용은 REF-A-05를 본다.

## 지표 계산 기준
모든 지표는 한 번의 참여(10라운드)를 단위로 모으고, 선택한 기간의 평균을 표시한다.

| 지표 | 계산 | 단위 |
| 정확하게 선택 | 참여별 성공 라운드 수 ÷ 참여 횟수 | n / 10 |
| 평균 반응 시간 | 라운드별 시간 합 ÷ 라운드 수 | 초 |
| 다른 선택 | 참여별 횟수 합 ÷ 참여 횟수 | 번 |
| 도움 받은 횟수 | 참여별 발동 횟수 합 ÷ 참여 횟수 | 번 |

힌트를 받고 성공한 경우도 성공에 포함하고, 일시정지 시간은 반응 시간에서 뺀다. 기간 안에 참여가 없으면 값을 0으로 쓰지 않고 「기록 없음」으로 비운다. 자세한 내용은 REF-A-07을 본다.

## 탭 두 종류

| 위치 | 탭 | 하는 일 |

| 그래프 위 | 정확하게 선택 / 반응 시간 / 다른 선택 / 도움 | 그래프에 어느 지표를 그릴지 고른다 (REF-A-05) |

## 활동별 지표 4종

| 자리 | ① 수확하기 | ② 장보기 | ③ 요리하기 |
| 1 | 정확하게 선택 | 제대로 산 재료 | 재료를 맞게 담음 |
| 2 | 평균 반응 시간 | 평균 반응 시간 | 평균 반응 시간 |
| 3 | 다른 선택 | 다르게 산 재료 | 재료가 달랐던 음식 |
| 4 | 도움 받은 횟수 | 도움 받은 횟수 | 도움 받은 횟수 |

축반전 — 2 · 3 · 4번은 「낮을수록 좋은」 지표라, 막대가 커지는 방향이 좋아진 것으로 읽히게 한다. 실제 값은 라벨로 함께 보여준다. ADM-006의 운영 수치(참여자 수 · 참여 횟수)에는 적용하지 않는다.
