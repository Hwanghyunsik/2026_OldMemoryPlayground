# Docs — 작업용 기획 참조 문서

`Assets/Planning/`의 원본(docx·xlsx·pdf)은 에디터에서 바로 읽기 어려우므로, 텍스트로 추출·정리한 사본을 여기에 둔다.
**내용이 다르면 항상 원본과 07 통합인계자료가 우선한다.** 이 폴더는 읽기 편의용이며, 기획 변경은 반드시 원본 기준으로 반영한다.

## 구현 시 확인 순서

1. 기능 단위 착수 → `03_기능정의서`에서 해당 FN 항목과 화면 코드 확인
2. 게임 콘텐츠 데이터 → `04_게임구성표`의 라운드 표를 그대로 데이터화 (남은 결정 없음 · 전부 확정)
3. 화면 레이아웃 → `01_화면설계서` 해당 페이지 + `02_프로토타입` 동작 확인
4. 규칙이 애매하거나 문서끼리 다름 → `07_통합인계자료` 해당 절 검색 (목차 파일 활용)
5. 연출·자산 요건 → `05_발주서`의 상태·연출 시트와 금지 사항
